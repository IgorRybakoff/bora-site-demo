# BORA 2.0 — демонстрационная главная страница

Это концепция нового корпоративного сайта для юридического сопровождения строительных контрактов и закупок.

## Просмотр

Файл `index.html` — самостоятельная адаптивная HTML-страница без сборки.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, затем **main / (root)**, сохраните. После публикации сайт будет доступен по адресу https://igorrybakoff.github.io/bora-site-demo/ .

## Важно

Это демонстрационный макет, не официальный сайт BORA. Блоки кейсов — образцы структуры, а не реальные результаты. Контакты взяты из исходного сайта, требуют подтверждения владельцем. Формы сбора персональных данных не реализованы.
